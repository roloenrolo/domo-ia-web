# Fuente del generador de tarjetas

El generador (`generar.py`) y sus datos (`datos.json`) salieron de este repo el
23-ago-2026: es un repo público y se servían en domo-ia.com.

Ahora viven en el repo privado, en `ConversIA-repo/landing-domo-ia/tarjeta-fuente/`.
El script escribe su salida acá, en `tarjeta/`. Requiere el paquete `segno`.

Las tarjetas generadas llevan `noindex, follow` desde la plantilla: son páginas de
contacto que se reparten por link, no contenido para buscadores.
